## 新增

- 备份统一存到 `data/backups/kaogong-<实例标识>/`，个人侧只留「云端快照」和「本地 JSON」两个入口。
- 快照列表能看到全部快照，并标注来源：每日自动、手动创建、导入前保护、恢复前保护。
- 每日快照改用 `settings.last_daily_snapshot` 记日期，0 点服务没运行时，启动后会补做当天那份。

## 修复

- 修复 0 点服务未运行导致当天快照整天空缺。
- 修复快照放在 `backups/` 根目录时列表扫不到、下载却能取到的问题。
- 快照写入后执行 `PRAGMA integrity_check`，校验失败会删除半截文件并返回错误，不再出现「提示成功但文件是坏的」。
- 删除账号时一并删除该账号的云端快照目录，服务器不留已注销账号的数据。
- 个人快照的列表、下载、恢复、删除全部从 token 取 uid，其他账号拿不到也删不掉；含 `../` 的文件名一律返回 400。

## 删除

- 移除「全库备份根目录」「个人备份目录」设置与接口，以及 `backup_local_path`、`personal_backup_path` 两个配置项。升级时旧路径里的快照会自动收编到实例目录。
