以前只能在题干上划线和用画笔画圈，想写一句「先看材料」「数字核对两遍」得另外找地方记。这版给答题区加了文字标注：双击落点出现光标，写完回车即落笔。

*这是草稿。v1.7.0、v1.7.1、v1.7.2 也还没有对应的 Release，发之前建议先补上，或者把这三版合并成一条。*

## 新增

- **双击写字**：练习和复习界面里，左键双击答题区任意位置，落点处直接出现带光标的输入框。没开画笔时双击答题区空白处同样可用，双击正文仍然是浏览器选词。
- **文字工具**：工具条新增「T 文字」，手机悬浮钮多了第三枚「T」。开启后单击落点即可写字，适合连续标注；手机上长按该钮可以调字号。
- **颜色跟随画笔**：文字颜色始终跟当前画笔一致。编辑过程中切换颜色，输入框里的字会同步变色，落笔就是新颜色。
- **滚轮调字号**：输入状态下滚轮直接改字号，屏幕上会提示当前 px，不会连带缩放画布。
- **记住上次字号**：默认 16px，和正文文字接近。每次调整后写入本地，下次双击沿用上一次的大小，范围 10–72px。
- **可以撤销**：落笔后和手写笔迹一样能撤销和回退。文字写进画布，随题目保存，切题回来、刷新续做都在。

## 顺手修的

- 双击落点不再留小黑点。画笔改成真正落墨时才记撤销点，双击时的两次空点击不产生墨迹，也不污染撤销栈。
- 写到纸边会自动折行，长句不会画到画布外面被裁掉。
- 粘贴时剥掉外部样式，避免把网页字体和颜色带进画布。
- 和已有手势互不干扰：文字框内的点选、拖选不触发作答，也不触发框选划线。`Enter` 落笔，`Esc` 取消，点别处自动落笔。

## 升级

没有数据库结构变化，直接替换代码即可，已有笔迹、划线、备份和管理员配置都不受影响。

文字标注保存在浏览器本地的答题笔迹里，和画笔一致，不写入服务端题库。换浏览器或清缓存会丢。
