## 新增

- 双击答题区任意位置写字，落点处直接出现输入框，回车落笔。
- 工具条新增「T 文字」，手机悬浮钮新增第三枚「T」，开启后单击落点即可写字。
- 文字颜色跟随当前画笔，编辑中切换颜色会同步变色。
- 输入状态下滚轮调字号，默认 16px，范围 10–72px，下次双击沿用上次大小。
- 文字写进画布，随题目笔迹保存，切题回来和刷新续做都在，可撤销。

## 修复

- 双击落点不再留小黑点。画笔改为真正落墨时才记撤销点，双击的两次空点击不产生墨迹。
- 长句写到纸边自动折行，不会画到画布外面被裁掉。
- 粘贴时剥掉外部样式，避免把网页字体和颜色带进画布。
- 文字框内的点选、拖选不触发作答，也不触发框选划线。

## 删除

- 无。
