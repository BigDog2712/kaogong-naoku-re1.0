# 题库构成

**506 份试卷，2008–2026 年，31 个省区市加国考、选调、市考，共 27,506 道题。**

其中 2016–2026 年这十一年的题占 27,458 道，是练习的主力。

## 试卷命名示例

每道题都能溯源到具体试卷，名字长这样：

- 2025年国家公务员录用考试《行测》题（副省级）
- 2024年江苏公务员录用考试《行测》题（A类）
- 2016年423联考《行测》题（浙江A卷）
- 2024年甘肃公务员录用考试《行测》题（网友回忆版）

真题以各考试当年的考生回忆版为基础整理，这是国内公考题库的通行做法，个别早年题量偏少属正常现象。

## 关于题量的疑问

上游 [ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti) 标称 58,890 题，本项目是 27,506 题。差别在于计数方式：上游算的是题目行数，同一道联考题在几十个省卷里各算一次；本项目按题目去重。

按题去重后上游有 25,382 道不同的题，本项目覆盖 25,271 道，覆盖率 99.56%，另有 158 道上游没有的更早年真题。完整账目见 [题库差距核查报告.md](题库差距核查报告.md)，缺题明细见 [题库缺口清单_上游有本地无.csv](题库缺口清单_上游有本地无.csv)。
